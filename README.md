# Mental Math — тренажёр устного счёта

Готовый адаптивный PWA для iPhone и Ubuntu. Пять режимов: **Сложение**, **Умножение**, **Память**, **Накопление**, **Bingo**. Тёмный интерфейс, адаптивная сложность, статистика, резервные копии.

## Запуск на Ubuntu

1. Распакуйте архив.
2. Откройте терминал в папке `mental-math-trainer`.
3. Запустите локальный сервер (нужен для проверки PWA):

   ```bash
   python3 -m http.server 8000
   ```
4. Откройте http://localhost:8000

Остановить сервер: `Ctrl+C`.

## Публикация через Git и GitHub Pages

1. Создайте **публичный** пустой репозиторий `mental-math-trainer` на https://github.com/new (без автоматического README).
2. В терминале Ubuntu перейдите в папку проекта и выполните:

   ```bash
   cd ~/mental-math-trainer
   git init
   git add .
   git commit -m "Initial Mental Math PWA"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/mental-math-trainer.git
   git push -u origin main
   ```

   Замените `ВАШ_ЛОГИН` на логин GitHub. Если Git запросит пароль при HTTPS push, используйте GitHub CLI (`gh auth login`) или персональный токен, а не пароль аккаунта.
3. В репозитории GitHub откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем **Save**.
5. После публикации сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/mental-math-trainer/`.

### iPhone

Откройте опубликованный адрес в Safari → **Поделиться** → **На экран «Домой»** → **Добавить**. Для первого запуска нужен интернет. После того как файлы сайта закешируются, основные функции работают офлайн. GitHub Pages продолжит работать, когда ноутбук выключен.

## Обновления

```bash
git add .
git commit -m "Update trainer"
git push
```

GitHub Pages автоматически опубликует новую версию. Для обновления офлайн-кеша при изменениях файлов можно увеличить версию `CACHE` в `sw.js`.

## Как устроены упражнения

- **Сложение:** два больших числа; разрядность увеличивается с уровнем.
- **Умножение:** два множителя с растущими диапазонами.
- **Память:** пример скрывается автоматически через 3/5/8 секунд или вручную; можно посмотреть снова.
- **Накопление:** каждый следующий шаг показывает только прибавляемое число; в ответ нужно вводить **полную накопленную сумму**.
- **Bingo:** каждый шаг показывает `число рулетки × множитель`; в ответ нужно вводить **полную накопленную сумму всех произведений**. Используются числа 1–36 (0 не меняет сумму).

Проверка: минимум 8 последних ответов на текущем уровне должны быть правильными подряд для повышения; также повышение происходит при 9/10 правильных, снижение — при менее 5/10. Максимальный уровень — 12. Правильная накопленная сумма используется на следующем шаге, даже если пользователь ошибся: ошибка не переносится на все следующие примеры.

## Хранение данных

Данные сохраняются в `localStorage` **на конкретном устройстве и браузере**. Автоматической синхронизации между iPhone и Ubuntu нет. Для переноса: **Настройки → Экспорт JSON**, затем **Импорт JSON** на другом устройстве. Очистка данных сайта может удалить статистику — регулярно делайте резервную копию.

## Ограничения

- Не требуется Python/Flask-сервер на GitHub Pages; сайт статический.
- Для публикации GitHub Pages репозиторий в этом сценарии публичный: не размещайте там секреты и личные данные.
- PWA работает офлайн после успешной первой загрузки и кеширования; доступность кеша зависит от браузера и его политики очистки.
- Тренажёр не использует серверную базу данных и не поддерживает аккаунты.
